# Agent Instructions

This project runs under the Universal Agent Harness (works with Cursor, Copilot, Codex and others
that read `AGENTS.md`).

Before doing anything, read and obey `.agent-harness/AGENTS_CORE.md`, then `.agentconfig.json` and
`.agent-harness/memory/ctx_memory.md`. If `.agentconfig.json` says `PENDING_SETUP`, run
`.agent-harness/SETUP_PROMPT.md` first.
